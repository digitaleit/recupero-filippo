# Rotta 26 — Recupero Filippo

## Avvio su Mac

1. Apri la cartella `recupero-filippo`.
2. Fai doppio clic su `index.html`.
3. La webapp si apre nel browser e funziona senza Internet e senza server.

I progressi, i punti e le risposte vengono salvati automaticamente nel browser del Mac. Per mantenere i dati usa sempre lo stesso browser e non cancellare i dati dei siti.
